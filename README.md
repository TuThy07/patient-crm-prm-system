# Patient CRM/PRM System

**Hệ thống quản lý quan hệ bệnh nhân**

## 1. Giới thiệu dự án | About the Project

Patient CRM/PRM là dự án học thuật theo nhóm về hệ thống quản lý quan hệ bệnh nhân.

Dự án tập trung vào các nghiệp vụ chính như quản lý thông tin bệnh nhân, đặt lịch khám, quản lý lịch hẹn, quản lý bác sĩ và tiếp nhận phản hồi.

Hệ thống có 3 nhóm người dùng: Patient, Doctor và Admin.

This is an academic group project focusing on patient information management, appointment scheduling, doctor management, and feedback handling.

**Project Information**
- Project Type: Academic Group Project
- Domain: Healthcare Management
- My Role: Business Analyst & Frontend Developer

## 2. Chức năng chính | Main Features

1. User Authentication – Đăng ký và đăng nhập.
2. Patient Information Management – Quản lý thông tin bệnh nhân.
3. Doctor Management – Quản lý bác sĩ.
4. Appointment Booking – Đặt lịch khám.
5. Appointment Management – Quản lý lịch hẹn.
6. Follow-up Recommendations – Đề xuất tái khám.
7. Feedback Management – Quản lý phản hồi.
8. Role-based Access Management – Quản lý phân quyền người dùng.
9. Dashboard and Statistics – Dashboard và thống kê.

## 8. Cách chạy dự án | How to Run

**Yêu cầu:** Trình duyệt web và Visual Studio Code.

1. Clone repository:

   ```bash
   git clone https://github.com/TuThy07/patient-crm-prm-system.git
   ```
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file `index.html` bằng Live Server.
4. Trải nghiệm các giao diện Patient, Doctor và Admin.
